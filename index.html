双色判定

玩法说明

音符从上方落下，在到达判定线时按下对应按键。

  • 按键：默认 D F J K，可在设置里改。
  • 菱形音符：单键击打。
  • 白边方块：特殊音符，击打时同时按住 空格，分数 ×2。
  • 长条：按下头部并保持，在尾端松手；判定看松手时机。
  • 判定：JUST ±48ms（100%），RUSH/COOL ±145ms（50%），超出即 MISS。
  • 分数：满分 1,000,000，按音符权重平均分配。
  • 评级：SSS 100万 / SS 95万 / S 90万 / AAA 80万 / AA 75万 / A 70万 / B+ 65万 / B 60万 / C 50万。

手机 / 平板：直接点击屏幕下方四个键位区域即可。
